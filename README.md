# 📘 SQL Student Result Management System
A PostgreSQL-based Student Result Management System to manage students, subjects, marks, and generate grades using SQL queries.

A simple PostgreSQL-based Student Result Management System.

## 🚀 Features
- Manage Students
- Manage Subjects
- Store Marks
- Calculate Total & Average
- Generate Grades
- Subject-wise Topper Query

## 🛠️ Technologies Used
- PostgreSQL
- SQL (DDL, DML, JOINS, GROUP BY, CASE)

## 📂 Project Structure
- schema.sql → Database and tables creation
- data.sql → Sample data insertion
- queries.sql → Result generation queries

## ▶️ How to Run

1. Open PostgreSQL (psql)
2. Run:
   \i schema.sql
3. Run:
   \i data.sql
4. Run:
   \i queries.sql

## 📊 Concepts Covered
- Primary Key
- Foreign Key
- JOIN
- GROUP BY
- Aggregate Functions
- CASE Statement
